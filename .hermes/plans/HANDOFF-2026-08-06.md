## Pitfalls / gotchas
- transition(newState) must map menu/playing/boss explicitly — NO default-boss (was bug, `437cd19`)
- `_scheduledNodes` self-removing via `_pushScheduled(osc, g, ms)` — never `push({stop})` without removing entry (leaks)
- Pads pushed persistent (no auto-remove) — stopped on transition
- Pool API: `acquire()/release()/forEach/count` getter — no `get()`, no `used`
- NO `ctx.filter` (Android slow) — blur via drawImage down/upscale
- Audio: `getSfxBus()/getMusicBus()/ensure()` on AudioManager; ctx stays `suspended` in headless — needs first real gesture (normal)
- SfxEngine: all synths schedule oscillators that self-stop; wired via `g.audio.ensure()` + `g.sfx.<name>()`
- Browser reload required after edits; stale DOM "no canvas" ≠ code error; `#game` null means tab lost → re-navigate
- Synthetic tap helper `window.__click(sx,sy)` fabricated by eval + `mousedown/up` at scene coords mapped via `let + (x/400)*w`
